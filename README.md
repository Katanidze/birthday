# Только для своих

Статический сайт для GitHub Pages. Не требует сборки или установки зависимостей.

## Публикация

1. Загрузите `index.html`, `style.css`, `questions.js`, `app.js` и `.nojekyll` в корень своего GitHub-репозитория.
2. В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root).
3. После публикации адрес будет вида `https://ИМЯ.github.io/РЕПОЗИТОРИЙ/`. Именно его нужно поместить в QR-код. Проверьте ссылку с телефона перед печатью.

## Настройка

- Вопросы и правильные ответы находятся в `questions.js`.
- Вопрос о дате присяги выключен (`enabled: false`). Заполните `answer` и поменяйте `enabled` на `true`, когда дата станет известна.
- Финальный текст и адрес находятся в функции `finish` файла `app.js`.
- Фотография пока не используется. Иллюстрация подарка создана средствами CSS.

## Правила

14 активных вопросов выдаются в случайном порядке без повторений. После первой ошибки задаётся ещё 1–2 вопроса, если они остались, затем показывается провал. Ошибка на последнем вопросе завершает тест сразу. Неверный ответ не раскрывается. Победа возможна только при всех верных ответах. Повторная попытка и перезагрузка начинают тест заново.

Номера принимают русские и соответствующие латинские буквы, любой регистр и пробелы. Даты принимаются с точками, дефисами, косыми чертами или без разделителей. Ответы находятся в исходниках: это дружеский тест, а не защита от просмотра кода.

Для локального просмотра запустите `python3 -m http.server 8080` в этой папке и откройте `http://localhost:8080`.
