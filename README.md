# Только для своих

Сайт: https://katanidze.github.io/birthday/
Репозиторий: https://github.com/Katanidze/birthday

Статический сайт для GitHub Pages, без сборки и зависимостей.

## Тест

Банк содержит 26 вопросов: 9 лёгких, 9 средних и 8 сложных. Каждая попытка состоит из 10 или 11 вопросов: 3 лёгких, 4 средних, 3 или 4 сложных. Этапы идут от лёгкого к сложному, внутри каждого вопросы выбираются случайно и перемешиваются. Повторов в одной попытке нет. Следующая попытка получает другой набор; при доступном sessionStorage это сохраняется после перезагрузки вкладки.

Бонусный вопрос включается случайно среди средних и входит в общий лимит. Оба ответа верны. Дата дембеля — 03.07.2017.

Любая ошибка ведёт к провалу после ещё 1–2 вопросов, если они остались. Последняя ошибка завершает тест сразу. Правильность отдельных ответов не раскрывается. Победа требует всех правильных ответов.

## Изменения

Вопросы находятся в questions.js. difficulty: easy / medium / hard; answer — один правильный ответ, answers — несколько. Логика и финальный текст находятся в app.js, оформление — в style.css.

Номера принимают русские и соответствующие латинские буквы, любой регистр и пробелы. Даты принимаются с точками, дефисами, косыми чертами или без разделителей. Ответы доступны в исходниках: это дружеский тест, а не защита от просмотра кода.

## Публикация

GitHub Settings → Pages → Deploy from a branch → main → / (root).
После отправки изменений сайт обновляется по прежнему адресу. QR-код менять не нужно.

Локальный просмотр: python3 -m http.server 8080.
Проверка логики: node tests/quiz.test.cjs.
