# От души душевно в душу

Готовые файлы для https://katanidze.github.io/birthday/.

## Загрузка

Загрузите в корень репозитория birthday все четыре файла: index.html, app.js, questions.js, style.css. Обязательно замените index.html: в нём обновлены заголовок, подпись и версии ресурсов для обхода старого кэша. Архив целиком загружать не нужно.

## Поведение

На входе — обезьяна с тарелками, 3,6 секунды, без звука. Каждая попытка: 3 лёгких, 4 средних, 3 сложных вопроса и фиксированный бонус «Сосал?» последним, 11-м. Бонус исключён из случайной подборки; оба ответа верны. После ошибки по-прежнему провал через 1–2 дополнительных вопроса, если остались: бонус доступен только при достижении конца теста.

Даты вводятся через системный календарь (включая iPhone). При победе — конфетти и десятисекундная шутка, затем финальная страница с повторным конфетти и адресом. При системном уменьшении движения анимации отключаются, текст остаётся видимым.

Для проверки: node tests/quiz.test.cjs. Для локального просмотра: python3 -m http.server 8080.

При фиксации любого ответа из баклажана разлетаются капли на весь экран (1,05 секунды). Повторные нажатия блокируются; эффект не раскрывает правильность ответа. При уменьшении движения переход происходит сразу.
